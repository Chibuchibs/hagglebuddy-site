# hagglebuddy.com

The published website for **HaggleBuddy: Market Prices**, served by GitHub Pages.

This repo holds only the deployed files. The source of truth is `website/` in the
app repo — edit there, then run `website/deploy.sh`, which syncs and pushes here.

Moved off Netlify on 2026-10-18: the free plan allows 300 credits/month and a
production deploy costs 15, i.e. 20 deploys a month shared across the whole team.
